# Matemagica

Il Duolingo della matematica: giochi brevi, da telefono, che allenano la mente.
Un progetto di Jack e suo papà.

**Gioca:** https://matemagica-teal.vercel.app

```bash
npm install
npm run dev      # sviluppo
npm run simula   # partite simulate per tarare difficoltà e stelle
npm run verifica # 46.000 quesiti generati: risolvibili, coerenti, senza trucchi
```

Sette giochi (4 arcade, 3 rompicapo), un sentiero misto di 40 livelli, una palestra e una
collezione di storie. Si installa sul telefono come un'app e funziona offline.

Contesto, regole e piano: [`CLAUDE.md`](CLAUDE.md).
