# shell — il guscio arcade

Qui vive **tutto** ciò che è comune ai minigiochi: timer, vite, combo, punteggio,
feedback giusto/sbagliato, overlay di risultato, assegnazione stelle, hook audio.

Migliorare il juice qui migliora tutti i giochi insieme: è il motivo per cui il
guscio esiste. Il contratto che le cartucce implementano è in `types.ts`.

**Da costruire in M1.**
